# Linux Security Command Lab

Hands-on Linux command-line lab covering file management, navigation, permissions, and system/process monitoring.

## 🎯 Objectives

- Practice essential Linux command-line operations
- Understand Linux file and directory management
- Explore file permissions and `chmod`
- Learn basic process monitoring commands
- Build practical Linux skills for cybersecurity

## 🛠️ Lab Environment

- Linux / Kali Linux
- Virtual machine environment
- Command-line interface
